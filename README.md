# DB Análisis

**C.A.P. · Análisis Táctico de Pelotas Paradas**

App PWA para el cuerpo técnico. Registro y análisis de pelotas paradas a favor y en contra — córners y tiros libres — con filtro de jugadores por partido.

## Funciones
- Login con PIN
- Filtro de plantel (titulares y suplentes)
- Pelotas paradas a favor: córner y tiro libre
- Pelotas paradas en contra: córner y tiro libre
- Historial de partidos guardado en el dispositivo
- Exportar / imprimir en PDF

## Stack
- HTML + CSS + JS vanilla (single file)
- PWA (instalable, funciona offline)
- localStorage para persistencia

## Deploy
Deployado en Vercel. Cada push a `main` actualiza la app automáticamente.
